# Churros "La Pinta" — demo conceptual

Landing page de una sola pantalla para una churrería local en Villa de Pozos, San Luis Potosí.
**Proyecto conceptual de portafolio**: no existe relación comercial con el negocio y los datos
(menú, precios, horarios) son ilustrativos. La página se sirve con `noindex, nofollow`.

- HTML + CSS, sin dependencias ni build. Un solo archivo.
- Mobile-first, ilustraciones SVG inline, tipografía variable.
- SEO on-page: meta description, Open Graph, favicon SVG y schema.org `Restaurant`.

Demo: https://danielledezmana.github.io/churros-la-pinta-demo/
